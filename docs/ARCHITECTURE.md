# 架构说明

## 设计原则

型号库存属于确定性业务数据，不能交给大模型推断。

推荐处理链：

1. 消息预处理
2. 售后高风险规则
3. 手机型号查询
4. 固定业务规则
5. AI知识问答
6. 转人工兜底

## 模块

- `normalization.py`：品牌、材质、型号标准化
- `importer.py`：XLSX/CSV 导入
- `models.py`：型号支持与未知型号数据表
- `service.py`：精确查询、相似型号、未知型号记录
- `cli.py`：本地验证和自动化入口

## 下一阶段适配

`adapters/customer_agent` 将负责把该核心服务接入原 Customer-Agent 的消息处理器链，但不会把原仓库作为本仓库的主开发分支。
